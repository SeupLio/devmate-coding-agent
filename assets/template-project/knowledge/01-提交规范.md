# 提交规范

本项目遵循 **Conventional Commits**，提交信息必须用祈使句、不加句号。

## 格式

```
<type>(<scope>): <subject>

<body>
```

## type 取值

| type | 用途 |
|---|---|
| `feat` | 新增功能 |
| `fix` | 修 bug |
| `refactor` | 重构（不改变外部行为） |
| `docs` | 只改文档 |
| `test` | 只改测试 |
| `chore` | 构建/依赖/杂项 |

## 硬性要求

1. **subject 不超过 50 字符**，用中文或英文均可，但同一仓库内保持一致。
2. 破坏性变更必须在 body 里写 `BREAKING CHANGE:` 开头的一段。
3. **一个提交只做一件事**。修 bug 和重构不要混在一个提交里。
4. 提交前必须保证 `node --test` 全绿。

## 反例

```
update          ← 没说改了什么
fix bug         ← 没说修什么 bug
修复了一个问题，另外顺便重构了一下    ← 两件事混在一起，且用了句号
```

## 正例

```
fix(mathutils): 修正 average 的分母

原实现用 nums.length - 1 作分母，导致结果偏大。
```
