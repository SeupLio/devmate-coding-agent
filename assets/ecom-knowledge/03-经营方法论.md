# 商家经营方法论

服务商做经营诊断时的判断框架。诊断不是罗列数据，而是**找到最该改的那一项**。

## 核心漏斗

```
曝光 → 进店 → 加购 → 下单 → 支付 → 复购
```

每一环的转化率都对标同行，**短板环节就是改进优先级最高的地方**。

## 关键指标与达标线（服饰/美妆等大类目参考）

| 指标 | 健康线 | 预警线 | 说明 |
|---|---|---|---|
| 支付转化率 | ≥ 2.5% | < 2% | 低于 2% 说明流量不精准或详情页/价格有问题 |
| 退款率 | ≤ 8% | > 10% | 高退款多是质量、描述不符或尺码问题 |
| 客服响应 | ≤ 30s | > 60s | 响应慢直接拉低转化与体验分 |
| 进店量（月） | ≥ 3000 | < 1000 | 低进店说明曝光或点击率不足 |
| 复购率 | ≥ 15% | < 8% | 低复购说明产品力或会员运营弱 |

## 诊断优先级：先看「影响最大且最好改」的

1. **客服响应慢** —— 最容易改（加人/挂机器人），见效快，先说这个建立信任。
2. **转化率低** —— 拆成「流量不精准」还是「承接不行」：
   - 曝光高但点击低 → 主图/标题/价格问题
   - 点击高但下单低 → 详情页/评价/SKU 问题
3. **退款率高** —— 看退款原因分布，质量类要溯源供应链，描述类要改详情页。
4. **流量不足** —— 先做免费流量（搜索优化、短视频），再谈付费投放。

## 不同规模商家的策略差异

- **KA（月GMV≥50万）**：关注利润率与活动资源位，谈的是「增量」与「品牌」。
- **腰部（10~50万）**：关注稳定增长，最需要标准化运营 SOP。
- **长尾（<10万）**：关注「从 0 到 1」，先解决基础流量与转化，别谈太复杂的打法。

## 诊断输出格式（给商家看的）

- 一句话结论：「您家最大的问题是 X，预计改进后能带来 Y」。
- 2~3 条可执行动作，每条带**负责人 + 时间 + 预期指标**。
- 不要一次给十条建议 —— 商家做不完，反而失去信任。
